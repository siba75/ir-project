# قائمة جاهزية مشروع نظم استرجاع المعلومات

## المنجز حالياً

- بنية SOA مقسمة إلى خدمات مستقلة.
- واجهة Streamlit لاختيار مجموعة البيانات ونموذج الاسترجاع.
- دعم TF-IDF و BM25 و Embedding و Hybrid Parallel و Hybrid Serial.
- التحكم بمعاملات BM25: `k1` و `b`.
- استخدام FAISS كـ vector store للبحث الدلالي.
- Query refinement بإضافة مرادفات.
- تقارير تقييم تعرض Precision@10 و Recall@10 و MRR و MAP و nDCG@10.
- ثلاث ميزات إضافية ظاهرة:
  - Vector stores باستخدام FAISS.
  - Personalization باستخدام سجل البحث.
  - Result clustering للوثائق المسترجعة في الواجهة.

## نقاط يجب إكمالها قبل التسليم النهائي

1. استبدال Cranfield و SciFact بمجموعتي بيانات تحققان شرط أكثر من 200K وثيقة لكل Dataset.
2. التأكد أن كل Dataset تحتوي على queries و qrels.
3. بناء inverted/BM25/vector indexes لكل Dataset نهائية.
4. تشغيل التقييم لكل النماذج:
   - TF-IDF
   - BM25
   - Embedding
   - Hybrid Parallel
   - Hybrid Serial
5. إضافة تقييم قبل وبعد الميزات الإضافية.
6. توثيق الميزات الإضافية الثلاث ضمن التقرير وشرح أثرها قبل/بعد التقييم.
7. كتابة تقرير عربي يتضمن:
   - وصف Datasetين.
   - وصف كل Service.
   - مخطط Architecture.
   - شرح SOA والتواصل بين الخدمات.
   - تحليل نتائج التقييم.
   - سبب اختيار معاملات BM25.
   - تقسيم العمل بين أعضاء الفريق السبعة.

## ملاحظة مهمة

النظام الحالي جيد كنسخة تطوير وعرض، لكنه لا يحقق شرط حجم الـ datasets كما هو مذكور في نص المشروع. لا ينصح بتسليمه نهائياً قبل معالجة هذه النقطة.
